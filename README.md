# Putri Tajudin — Portfolio

Personal portfolio for Putri Tajudin, an Information Engineering undergraduate
at Universitas Gadjah Mada. The site highlights data and technology projects,
campus experience, skills, coursework, and contact links.

## Tech Stack

- Next.js 16 and React 19
- TypeScript
- Tailwind CSS
- Framer Motion

## Getting Started

Install dependencies and run the local development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Project Structure

- `app/` — routes, layouts, and page metadata
- `components/` — reusable interface components
- `config/` — portfolio content, navigation, and site settings
- `public/` — profile, certificate, and project images

## Checks

```bash
npm run lint
npx tsc --noEmit

```
